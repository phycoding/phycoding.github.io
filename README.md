# 🎰 Premium Spin Wheel Game with Data Analytics

A professionally designed, fully-featured spin wheel game that collects comprehensive user analytics and stores them locally in the browser's IndexedDB database.

## ✨ Quick Overview

### 🎮 Game Features
- **Beautiful SVG Wheel** - Dynamically generated with smooth animations
- **Fair Random System** - Weighted probability distribution
- **Customizable Prizes** - Edit prizes, icons, and probabilities in real-time
- **Live Statistics** - Track total spins, wins, and win rate
- **Spin History** - View last 10 spins with timestamps
- **Confetti Effects** - Celebratory animations for wins
- **Responsive Design** - Works on mobile, tablet, and desktop

### 📊 Data Collection
- **GPS Location** - Latitude, longitude with accuracy
- **IP Geolocation** - City, region, country, ISP
- **Network Analytics** - Connection type, speed, latency
- **Device Profile** - OS, browser, screen size, CPU info
- **Complete Tracking** - Language, timezone, device memory
- **Local Storage** - All data stored in browser (IndexedDB)
- **Easy Export** - Download as JSON or CSV

### 🎨 Premium Design
- **Luxurious Dark Theme** - Navy background with gold accents
- **Smooth Animations** - Professional transitions
- **Interactive UI** - Hover effects and visual feedback
- **Eye-catching Typography** - Large, bold text
- **Modern Gradients** - Professional color schemes

## 🚀 Quick Start

1. Open `index.html` in your browser
2. Grant location permission when prompted
3. Click "🎯 SPIN THE WHEEL"
4. Click "📊 View Collected Data" to see analytics
5. Export data as JSON or CSV

## 📊 What Gets Collected

✅ **Location**: GPS coordinates, accuracy, altitude  
✅ **IP Info**: Public IP, city, country, ISP, timezone  
✅ **Network**: Connection type, speed, latency  
✅ **Device**: OS, browser, screen resolution, CPU cores  
✅ **Profile**: Language, device memory, timezone  
✅ **Timestamp**: Exact date/time of each spin  

## 💾 Local Database (IndexedDB)

- All data stored locally in browser
- Unlimited storage
- Data persists between sessions
- User can export and delete anytime
- No data sent to external servers

## 📱 Browser Support

✅ Chrome, Firefox, Safari, Edge, Opera  
⚠️ IE 11 (limited features)  
✅ Mobile browsers with full features
