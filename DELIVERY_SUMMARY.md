## 🚀 How to Use

### For End Users
1. Open `index.html` in web browser
2. Review privacy notice (optional)
3. Allow or deny location permission
4. Click "SPIN THE WHEEL" button
5. See result popup
6. Click "📊 View Collected Data" to see analytics
7. Click "Download JSON/CSV" to export

### For Developers
1. Review `TECHNICAL_DOCS.md` for architecture
2. Examine `index.html` source code
3. Check `FEATURES.md` for API details
4. Reference `TESTING_GUIDE.md` for testing

### For Administrators
1. Deploy to web server (HTTPS recommended)
2. Update privacy policy
3. Monitor collected data
4. Download reports regularly
